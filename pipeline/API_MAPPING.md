# API Mapping Documentation

## e뮤지엄 Open API

### Base URL
```
https://www.emuseum.go.kr/openapi
```
**Note**: The URL uses lowercase `openapi`, not `openApi` as sometimes shown in documentation.

### Endpoints Discovered

| Endpoint | Purpose | 
|----------|---------|
| `/openapi/code` | Code list lookup (museum codes, category codes) |
| `/openapi/relic/list` | Artifact list search with filters |
| `/openapi/relic/detail` | Single artifact detailed information |

### Authentication

**Required**: Yes - API key from 공공데이터포털 (data.go.kr)

1. Register at https://www.data.go.kr
2. Search for "전국 박물관 유물정보" (data set ID: 3036708)
3. Apply for API access (개발계정: 1,000 requests/day)
4. Use `serviceKey` parameter in requests

### Common Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `serviceKey` | string | Yes | Authentication key from 공공데이터포털 |
| `pageNo` | integer | Yes | Page number (1-indexed) |
| `numOfRows` | integer | Yes | Results per page (max 100 recommended) |

### Relic List Endpoint (`/relic/list`)

**Additional Parameters:**

| Parameter | Description | Example |
|-----------|-------------|---------|
| `ccbaKdcd` | Classification code (11=국보, 12=보물) | `11` |
| `name` | Search term | `백제` |
| `pageNo` | Page number | `1` |
| `numOfRows` | Results per page | `10` |

### Unique ID Strategy

The `id` field is generated by concatenating:
```
id = ccbaKdcd + ccbaAsno
```
Example: `ccbaKdcd=11` + `ccbaAsno=0083` → `id = "110083"`

### Image URL Construction

```
Base URL: https://www.emuseum.go.kr
Image Path: ccbaImage field value
Full URL: https://www.emuseum.go.kr{ccbaImage}

Example: ccbaImage = "/images/relic/11/0083.jpg"
Full URL: https://www.emuseum.go.kr/images/relic/11/0083.jpg
```

### Classification Codes (ccbaKdcd)

| Code | Type | 
|------|------|
| `11` | 국보 (National Treasure) |
| `12` | 보물 (Treasure) |

| Field | Description |
|-------|-------------|

## 공공데이터포털 API

```
https://www.data.go.kr/openapi
```

### Key Endpoints

The same e뮤지엄 API is accessible through 공공데이터포털 with dataset ID `3036708`.

**Related datasets:**
- `15104964`: 문화체육부_국립중앙박물관_e뮤지엄_유물정보
- `15121515`: 문화체육부_국립중앙박물관_유물정보

## Sample API Calls

```bash
# Get national treasures (국보) list
curl "https://www.emuseum.go.kr/openapi/relic/list?serviceKey=YOUR_KEY&pageNo=1&numOfRows=10&ccbaKdcd=11"

# Get treasure (보물) list
curl "https://www.emuseum.go.kr/openapi/relic/list?serviceKey=YOUR_KEY&pageNo=1&numOfRows=10&ccbaKdcd=12"

# Get artifact detail
curl "https://www.emuseum.go.kr/openapi/relic/detail?serviceKey=YOUR_KEY&id=110083"
```

---

## Notes

1. **Authentication Required**: All API calls require a valid `serviceKey` from 공공데이터포털.

2. **Response Format**: Default is XML. JSON samples are also available in `api_samples/`.

3. **Image Access**: Images are relative paths. Construct full URL using `https://www.emuseum.go.kr` as base.

4. **Unique ID**: Generate using `ccbaKdcd + ccbaAsno` (string concatenation, zero-padded).
